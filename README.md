# 🌿 Leaf Disease Detection using IBM watsonx.ai

## Project Overview

Leaf Disease Detection is an AI-powered web application that identifies plant leaf diseases from uploaded images. The application uses IBM watsonx.ai to analyze the image and provides the disease name along with treatment and prevention recommendations.

The project aims to help farmers, gardeners, and agriculture students quickly identify plant diseases and take appropriate action to improve plant health.

---

## Problem Statement

Plant diseases can reduce crop quality and yield if not identified early. Traditional diagnosis often requires expert knowledge, which may not always be available. This project provides a simple AI-based solution for faster disease identification.

---

## Solution

Users can upload an image of a plant leaf, and the application analyzes it using IBM watsonx.ai. The AI identifies the disease and provides useful information, including:

- Disease name
- Symptoms
- Treatment suggestions
- Prevention tips

---

## How It Works

1. Open the application.
2. Upload a plant leaf image.
3. The backend sends the image to IBM watsonx.ai.
4. The AI analyzes the image.
5. The application displays:
   - Disease name
   - Symptoms
   - Treatment suggestions
   - Prevention tips
